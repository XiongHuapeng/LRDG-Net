# Reference result snapshots

These read-only files were bundled from the finalized experiment outputs used to organize the manuscript tables. They are included for traceability and for `tools/verify_project.py` consistency checks.

They are **not** loaded by the training or evaluation workflows and should not be interpreted as generated by a fresh clone.

Included snapshots cover:

- LIDAROC cross-domain LRDG-Net summaries;
- baseline comparison summaries;
- G/A/R/G+A/G+R representation-ablation summaries;
- local-scale sensitivity summaries;
- strict AT128 external-evaluation metrics;
- final clean-reference AT128 calibration summaries and protocol metadata.

The separately supplied R-component ablation source code has been integrated into `paper_experiments/component_ablation/`. No component-level result snapshot was present in the uploaded code package, so none is fabricated here.
